# 密集计数

Define the inclusion rule before counting: distinguish an object from its parts, packaging, reflections and similar distractors. Partition the scene along stable boundaries such as shelves or rows. Assign boundary-crossing objects to the region containing their center; count each identity once. Keep per-region subtotals rather than estimating from density or regular spacing.

Request native-source crops for regions with unresolved small objects while retaining the overview. Overlapping crops show the same source objects and must not be summed as separate populations. Use the runtime's note action when persistent object marks help prevent recounting, keeping marks off identity-defining details. Review ambiguous candidates separately before combining subtotals.

Return the count with a compact breakdown when requested. If occlusion prevents an exact count, distinguish the visible count from any estimate instead of inventing hidden objects.

Finish with the runtime action=answer object. Its answer field is a string containing the requested output.
