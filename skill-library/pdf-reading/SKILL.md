# PDF 阅读

Establish the supplied page range and distinguish file-page indices from printed page numbers. Locate likely sections from headings or supplied page previews, then read the relevant pages at native detail. Keep a page overview with each crop so footnotes, units and qualifiers remain attached to their evidence. Tables continued on another page require the previous header and the continuation rows together.

Separate statements printed in the document from your own calculations or interpretation. Preserve the scope of a condition: a specification for one model, year or experiment does not apply automatically to the others. Cite the printed page number when visible, otherwise the supplied file-page index and filename. If only selected pages were supplied, limit claims to those pages; never claim that an absent statement does not exist anywhere in the document.

Return the requested answer with page references and any unresolved gaps. This skill consumes page images; it does not itself parse or render PDF files.

Finish with the runtime action=answer object. Its answer field is a string containing the requested output.
