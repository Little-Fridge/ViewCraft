# Public release · 2026-10-08

## Included

- The ViewCraft runtime and joint reader/interface evolution framework.
- JSONL custom tasks, local scorers, prediction, resume support, and benchmark adapters.
- A 12-item synthetic counting example with 6 train / 3 gate / 3 test items.
- Ten reusable gallery skills with reproducible case inputs, skill files,
  actual model records, and self-contained HTML presentations.
- Offline tests and portable environment-based model configuration.

The supplied case records identify GPT-6 Astra as the executor. The original
package reports that all ten reference checks passed on 2026-10-08. These are
single illustrative cases, not general accuracy measurements or evidence that
skill evolution improved those cases. Publication preparation does not rerun
live model calls.

## Publication layout

The repository retains source code, synthetic inputs, original recorded model
attachments/responses, and the gallery homepage. Each case keeps one standalone
`case/replay.html`; duplicate `case/run/replay.html` exports are omitted from
version control. They can be regenerated by the gallery builder. Environment
notes and tutorials live in `docs/`.

API credentials, private service endpoints, downloaded benchmark data, caches,
model weights, and experiment-run directories are not release artifacts.

## Reproduction boundary

This is a framework and example release. It does not include the original
benchmark datasets or archived paper experiment runs. Demo defaults and legacy
benchmark configurations do not reproduce every paper protocol or ablation.
Historical environment pins are a reference only, not a guarantee of identical
model outputs. Follow each dataset's own access and license terms.

Offline test doubles verify execution and data handling. They do not establish
real-model accuracy or reproduce the paper's result tables.
