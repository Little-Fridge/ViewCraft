# ViewCraft project page

Static HTML, CSS and JavaScript. Serve this directory with any static server. Paths are relative so the page can be hosted under a GitHub Pages project path.

The site includes original paper figures, the arXiv paper link, benchmark results and links to the reusable skill library. It does not publish internal gallery inputs or model-response records. The code repository and task skill library are public.

See [publishing instructions](../docs/website.md). Only website files should be sent to the public Pages deployment.
